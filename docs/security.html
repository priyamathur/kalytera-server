Data & security

What Kalytera stores, where it goes, how to delete it, and what happens to your agent if Kalytera is down.

What we store

DataStored
Each step your agent sends: input, output, tool calls (name, arguments, success, error, latency), metadataYes, until you delete it
The judge's scores and failure reason for each sessionYes, until you delete it
Rule checks (guard() decisions)Tool name, decision, rule — a hash of the arguments, not the arguments
Your accountEmail, organisation name. API keys are stored only as SHA-256 hashes.

Mask personal data before it leaves your servers

kalytera.init(redact=True) (or KALYTERA_REDACT=1) replaces email addresses, phone numbers and card numbers with [email], [phone], [card] in everything the SDK sends. Rules are still checked on the real values inside your process, so blocking works the same.

This is pattern matching, not a guarantee: names, street addresses and unusual formats are not caught.

Who processes it

  • Kalytera's API and database, hosted on Render. Every API call is scoped to your account; an agent name belongs to one account and other accounts can't read or write it.
  • Anthropic (Claude) scores each finished session: the session's steps and tool calls are sent to Anthropic's API for that one request. Nothing else is sent to an LLM; finding problems and drafting rules run on Kalytera's servers. See Anthropic's commercial terms.

Delete your data

  • One agent: dashboard → Overview → Delete this agent's data, or DELETE /agents/{agent_id}/data. Removes its sessions, scores, problems, rules, rule checks and labels. Can't be undone.
  • Your whole account: email priya@kalytera.ai.

There is no automatic expiry today: data is kept until you delete it.

Your agent if Kalytera is down

  • Recording runs on a background thread and never raises into your code.
  • Rules are checked inside your process from a local cache, refreshed in the background — no network call per tool call.
  • If Kalytera can't be reached, your tools still run: rule checks fail open.
  • Only rules you turned on with Start blocking can stop a call; new rules only watch.

Keep everything on your own infrastructure

Kalytera's server is open source and runs with Docker: self-host guide. Then nothing leaves your network except the judge's calls to the LLM provider you configure.

Not in place yet

No SOC 2 report, no signed DPA template and no automatic retention period yet. If you need any of these for a pilot, email priya@kalytera.ai.
